# 电脑小岛

第一课「计算机基础」的试玩：一张全屏画布，从地图依次走进七关、开宝箱，再任选第八关。

画面使用已批准的界面素材。图片打进 `src/pack.js`，字体放在本地。不访问网络，断网也可以玩。

## 打开

用电脑 Chrome：

- 双击 `index.html`。图片已经以 base64 写在 `src/pack.js` 里，这样直接用文件打开时，画面也能出来。
- 或者在这个目录执行 `python3 -m http.server`，再用浏览器打开给出的本地地址。

现在采用完整显示（FIT）：1280×800 的游戏构图等比居中，空余区域用同一场景的背景铺满。方窗和宽窗都保留完整操作区，HUD 按可见区域定位并在窗口大小改变时重摆。Retina 屏的内部画布最多使用 2 倍像素密度，玩法坐标保持不变。

M1 的离线几何检查可运行 `node --test tests/m1-layout.test.cjs`。本轮受执行环境限制，两种打开方式尚未完成 Chrome 实测；验证范围和待验收项见 [M1 验证记录](docs/m1-verification.md)。

字体是站酷快乐体和思源黑体的子集，授权在 `assets/ui-v1/fonts/` 的 OFL 文件里。没有从网上加载字体。

## 怎么玩

地图上点已经打开的圆牌，或点「出发」。上一关完成后，下一路点会亮起来。

| 关 | 关卡 | 做什么 |
|---|---|---|
| 1 | 开门热身 | 自己判断点星、开礼物、拖钥匙；挑战加入 Shift |
| 2 | 搬家小队 | 看后缀分类、比较整夹与逐件搬家、辨认同名路径 |
| 3 | 机器人出门 | 穿鞋三卡，刷牙先发现少一格，再补全顺序 |
| 4 | 机器人修 bug | 运行六步程序，找出并修改两处错误 |
| 5 | 看天气出门 | 填两种天气的做法，连续几天都要正确 |
| 6 | 乌龟画画 | 八卡正方形，改用一张重复卡画三角形 |
| 7 | 乌龟省步数 | 补缺边方形，独立推导六边形；八边形挑战选做 |
| 8 | 小岛大挑战（选做） | 最多五张卡，用顺序、条件和重复走六格路线 |

每关过关后可以选「挑战」，没有提示、不能失误，通关拿额外金星。完成前七关即可开宝箱、拿徽章，第八关不影响徽章。

- 左上角返回或 Esc：回地图，未完成的这一轮重新开始。
- 灯泡：看提示，算一次提示；自动出现的线索也计入提示。挑战没有灯泡；第七关六边形轮独立完成，不提供提示。
- 喇叭：静音，选择记在本机。
- Enter 或空格：运行；结算时回小岛。
- 乌龟关方向键：↑↓ 改重复次数，←→ 改角度。

★ 通关；★★ 失误和提示合计不超过两次；★★★ 不用提示且目标轮步数不超过标准。标准与计数口径、全部挑战、变更清单和验证限制见 [八关交付记录](docs/planb-levels.md)。

运行 `node --test tests/` 检查规则和离线资源。测试用模拟绘图对象执行真实玩法回调；当前受环境限制，两种打开方式仍需 Chrome 实测。


## 给大人的开关

孩子的画面上没有重置按钮。

| 做法 | 作用 |
|---|---|
| 地址后加 `?reset=1` | 清掉进度，再从头玩 |
| 按住 Shift 再按 R | 同样清掉进度并刷新 |
| 地址后加 `?unlock=all` | 八关都可进。只在这一次打开时有效，不写入存档 |
| 地址后加 `?calm=1` | 减少位移、缩放和粒子，声音和文字还在。系统开了「减少动态效果」时也会这样 |
| 地址后加 `?debug=1` | 左上角显示帧率 |

进度存在本机，键名是 `island2:v2`，自动迁移旧版四关成绩。旧版徽章不会提前打开新宝箱。
