# 概念游乐场 · 电脑小岛（周日试玩）

给 11–12 岁孩子的第一课试玩。打开就是一屏「电脑小岛」：4 关打磨过的关卡，外加 5 个还锁着的区域。进度只存在这台浏览器里。

## 怎么玩

用桌面 Chrome 打开 `index.html`（双击，或下面的本地服务器）。请用横屏。刷新会回到地图，已经过的关和星星还在。

```bash
python3 -m http.server 8765
```

然后打开 http://127.0.0.1:8765/

没有构建步骤。页面不请求任何外部字体、图片或脚本，断网也能玩。

## 周日这一条（已打磨）

上一关完成就解锁下一关。规则在 `island.js` 顶部的 `UNLOCK_RULE`：`mode: 'clear'`。改成 `mode: 'stars'`、`starsNeeded: 2` 就是「2 星解锁」。

| 顺序 | 名字 | 概念 | 玩法 |
|---|---|---|---|
| 1 | 开门热身 | 鼠标：单击、双击、拖动 | 点亮星星，双击打开礼物，把钥匙拖到门上 |
| 2 | 搬家小队 | 文件夹、路径 | 把文件拖进文件夹，再拖整个文件夹，然后照路径找到笔记 |
| 3 | 机器人出门 | 顺序、bug | 把指令卡排进格子，看机器人按顺序闹笑话 |
| 4 | 乌龟画画 | 重复 | 先一张张排卡片画正方形，再用「重复」画圆 |

四关都完成后，宝箱打开，掉出「电脑小岛岛主」。

每关都是：先玩 → 撞墙 → 一句提示 → 概念卡 → 最多 1 道三选一 → 结算。星星：完成 1 颗，题目一次选对 2 颗，没点过提示再加到 3 颗。
