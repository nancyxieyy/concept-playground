# 电脑小岛

第一课「计算机基础」的试玩：一张全屏画布，从地图走进四关，再回地图开宝箱。

画面使用已批准的界面素材。图片打进 `src/pack.js`，字体放在本地。不访问网络，断网也可以玩。

## 打开

用电脑 Chrome：

- 双击 `index.html`。图片已经以 base64 写在 `src/pack.js` 里，这样直接用文件打开时，画面也能出来。
- 或者在这个目录执行 `python3 -m http.server`，再用浏览器打开给出的本地地址。

现在采用完整显示（FIT）：1280×800 的游戏构图等比居中，空余区域用同一场景的背景铺满。方窗和宽窗都保留完整操作区，HUD 按可见区域定位并在窗口大小改变时重摆。Retina 屏的内部画布最多使用 2 倍像素密度，玩法坐标保持不变。

M1 的离线几何检查可运行 `node --test tests/m1-layout.test.cjs`。本轮受执行环境限制，两种打开方式尚未完成 Chrome 实测；验证范围和待验收项见 [M1 验证记录](docs/m1-verification.md)。

字体是站酷快乐体和思源黑体的子集，授权在 `assets/ui-v1/fonts/` 的 OFL 文件里。没有从网上加载字体。

Mac App 工程在 `app/`，构建与安装见 [Mac 使用说明](app/README.md)。根目录仍是网页源文件，打包时才复制到 `app/www/`。

## 怎么玩

地图上点已经打开的圆牌，或点「出发」。上一关完成后，下一路点会亮起来。

| 关卡 | 做什么 |
|---|---|
| 开门热身 | 点亮星星，双击礼物盒，把钥匙拖到门上 |
| 搬家小队 | 把文件放进对的箱子，再按路径找到小猫.png |
| 机器人出门 | 把指令排进格子，按运行。刷牙第一次会少一步 |
| 乌龟画画 | 先一步步画正方形，再用一张「重复」画出三角形 |

屏幕上的字很少。卡住时：同一目标连错两次会亮出黄圈，第三次会演示一次；大约 20 秒没有操作，正确目标会闪一下。答错没有红叉。

- 左上角返回或 Esc：回到地图。这一关不保存，下次重新开始，不弹确认。
- 灯泡：看提示，算一次提示。
- 喇叭：静音。选择记在本机。
- Enter 或空格：结算时回小岛；在机器人关和乌龟关相当于按运行。
- 乌龟关的方向键：↑↓ 改重复次数，←→ 改转弯角度。

每关一到三颗星。一次都没错是三颗，失误（点错和提示）合计不超过 2 次是两颗，再多是一颗。右上角的星豆按「1 颗星 = 1 颗星豆」占位显示，过关卡上写「+N 星豆」。

## 给大人的开关

孩子的画面上没有重置按钮。

| 做法 | 作用 |
|---|---|
| 地址后加 `?reset=1` | 清掉进度，再从头玩 |
| 按住 Shift 再按 R | 同样清掉进度并刷新 |
| 地址后加 `?unlock=all` | 四关都可进。只在这一次打开时有效，不写入存档 |
| 地址后加 `?calm=1` | 减少位移、缩放和粒子，声音和文字还在。系统开了「减少动态效果」时也会这样 |
| 地址后加 `?debug=1` | 左上角显示帧率 |
| Shift + Option（Alt）+ U | 切换四关全部解锁，不伪造通关或星星 |
| Shift + Option（Alt）+ C | 切换安静模式（减少动态效果），不静音 |
| Shift + Option（Alt）+ D | 切换调试帧率显示，发布版不打开开发者工具 |

三个组合键在 App 和网页都有效，再按一次关闭对应参数。操作会重载当前页面并回地图，未完成关卡重新开始，已保存进度保留；按住不放不会连续切换。系统开启「减少动态效果」时，关闭安静模式参数仍会尊重系统设置。参数在当前页面刷新后保留；彻底退出 App 后重新启动使用默认入口。Shift+R 只清进度，不关闭这些参数。

进度存在本机，键名是 `island2:v1`。通关和静音设置立即写入，不依赖关闭页面时保存；普通刷新不主动删除进度。App 和浏览器的存储相互独立，不自动迁移。
