# 电脑小岛

第一课「计算机基础」的试玩：一张全屏画布，从地图走进四关，再回地图开宝箱。

画面、按钮和 Lucky 都是代码画的。不加载字体、图片或声音文件，双击 `index.html` 就能玩，断网也可以。

## 打开

- 用电脑 Chrome 双击 `index.html`。
- 或者在这个目录执行 `python3 -m http.server`，再用浏览器打开给出的本地地址。

窗口保持 16:9 左右最合适。页面只有一块画布，没有滚动条。

## 怎么玩

地图上点已经打开的圆牌进入关卡。上一关完成后，下一路点会亮起来。

| 关卡 | 做什么 |
|---|---|
| 开门热身 | 点亮星星，双击礼物盒，把钥匙拖到门上 |
| 搬家小队 | 把文件放进对的箱子，再按路径找到小猫.png |
| 机器人出门 | 把指令排进格子，按运行。刷牙第一次会少一步 |
| 乌龟画画 | 先一步步画正方形，再用一张「重复」画出三角形 |

屏幕上的字很少。卡住时：同一目标连错两次会亮出黄圈，第三次会演示一次；大约 20 秒没有操作，正确目标会闪一下。

- 🏠 或 Esc：回到地图。这一关不保存，下次重新开始，不弹确认。
- 💡：看提示，算一次提示。
- 🔊：静音。选择记在本机。
- Enter 或空格：结算时回小岛；在机器人关和乌龟关相当于按运行。
- 乌龟关的方向键：↑↓ 改重复次数，←→ 改转弯角度。

星星：一次都没错是三颗，失误（点错和提示）合计不超过 2 次是两颗，再多是一颗。答错没有红叉，也不扣已有的星。

## 给大人的开关

孩子的画面上没有重置按钮。

| 做法 | 作用 |
|---|---|
| 地址后加 `?reset=1` | 清掉进度，再从头玩 |
| 按住 Shift 再按 R | 同样清掉进度并刷新 |
| 地址后加 `?unlock=all` | 四关都可进。只在这一次打开时有效，不写入存档 |
| 地址后加 `?calm=1` | 减少位移、缩放和粒子，声音和文字还在。系统开了「减少动态效果」时也会这样 |
| 地址后加 `?debug=1` | 左上角显示帧率 |

进度存在本机，键名是 `island2:v1`。
