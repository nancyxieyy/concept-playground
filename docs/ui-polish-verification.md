## 巡检入口

双击根目录 `index.html` 后，在地址末尾加 `?debug=1&qa=tour`；也可在仓库运行 `python3 -m http.server 8765`，打开 `http://localhost:8765/index.html?debug=1&qa=tour`。

仅两个参数同时存在才进入。普通页面、仅 `debug=1`、仅 `qa=tour` 和 App 的 Shift+Option+D 都不会自行启动巡检。移除参数并刷新即可恢复正常游戏。巡检使用全新内存进度，不读取、写入或重置孩子的存档，包括同时误带 `reset=1` 的情况。

顺序共 18 屏，稳定展示后每屏停 2.5 秒，循环播放：地图 → door-r1/r2/r3 → files-r1/r2/r3 → robot-r1/r2 → turtle-r1/r2 → files-r3-works → files-r3-draw → turtle-r2-controls → 四关各自的 result。标题例如 `qa:files-r3`。巡检停用玩法输入、发呆提示和 FPS 文字，使用减少动效模式，退出场景清理定时器；不通过自动通关来推进。
